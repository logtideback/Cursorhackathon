# ProofMode

Capture everyday agreements before they become disagreements.

A mobile-first web app MVP built for iPhone demo at the Cursor iOS hackathon.

## Quick start

```bash
npm install
npm run dev
```

Open on your iPhone or in Safari responsive mode (390px width).

## Features

- **Capture** — Add an optional photo and agreement note to generate a structured Proof Card
- **My Proofs** — Browse, filter, complete, and delete saved proof cards
- **Deterministic parser** — No AI API; keyword-based extraction of people, dates, and agreement types
- **localStorage** — All data persists locally in the browser

## Demo input

Try: *"I lent Alex my USB-C charger. He'll return it after demos."*

## Stack

- React 19 + Vite
- No backend, no auth, no external APIs
